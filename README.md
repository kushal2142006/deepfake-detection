# Deepfake Detection

## Overview
Deepfake Detection is an AI-powered project that identifies manipulated images and videos using deep learning techniques.

## Features
- Detects deepfake images/videos
- Data preprocessing
- Deep learning-based classification
- Performance evaluation

## Tech Stack
- Python
- Google Colab
- TensorFlow
- OpenCV
- NumPy
- Pandas

## Future Improvements
- Real-time video detection
